กล่องที่ 1: การวิเคราะห์ปัญหา (Problem Analysis)

เป็นจุดเริ่มต้นของทุกอย่าง ทำความเข้าใจว่า ปัญหาคืออะไร? ผู้ใช้ต้องการอะไร? ข้อมูลเข้า (Input) คืออะไร? และ ผลลัพธ์ (Output) คืออะไร? หากขั้นตอนนี้ผิดพลาด ขั้นตอนที่เหลือทั้งหมดจะผิดตาม!

2. โรงงานแนวคิด IPO (Input ➔ Process ➔ Output)

ลองเล่นเครื่องจักร IPO ด้านล่างเพื่อดูว่าข้อมูลเดินทางอย่างไรในคอมพิวเตอร์

📥

1. INPUT (นำเข้า)

รับข้อมูลที่จำเป็นต้องใช้

คลิกปุ่มนี้ 👆
⚙️

2. PROCESS (คำนวณ)

สูตรหรือเงื่อนไขจัดการข้อมูล

area = width * length
รอกดปุ่มประมวลผล...
📤

3. OUTPUT (แสดงผล)

ผลลัพธ์ที่โจทย์ต้องการ

40
หน่วย: ตารางหน่วย

📌 กรอบวิเคราะห์โจทย์ 5 หัวข้อ (ออกสอบบ่อยมาก):

1. สิ่งที่ต้องการ: เป้าหมายงาน
2. รูปแบบผลลัพธ์: หน้าตา Output
3. ข้อมูลนำเข้า: ตัวเลข/ข้อความที่ป้อน
4. ตัวแปร: ชื่อและชนิดตัวแปร
5. การประมวลผล: ลำดับขั้นตอนวิธี

3. ตัวแปร (Variables) vs ค่าคงที่ (Constants)

ลองกดปุ่มด้านล่างเพื่อสังเกตพฤติกรรมของกล่องทั้งสองแบบ

เปลี่ยนค่าได้เสมอ 📦

กล่องตัวแปร: score

ค่าใหม่จะ "ทับ" ค่าเก่าทันที (Overwrite)

ค่าปัจจุบัน: 50

เริ่มต้น: SET score = 50

🔒 ล็อคห้ามเปลี่ยน 🛡️

กล่องค่าคงที่: PI

กำหนดค่าไว้ครั้งแรกแล้ว ห้ามแก้ไขเด็ดขาด

ค่าตายตัว: 3.14

ปลอดภัย: ค่าคงที่ยังคงเป็น 3.14

🔢 จำนวนเต็ม (Integer): 1, 2, 5 ชิ้น 🎯 จำนวนจริง (Real/Float): 25.50 บาท, 3.14 🔤 ข้อความ (String): "สมชาย", "0812345678"* ⚖️ ตรรกะ (Boolean): TRUE, FALSE

*ข้อสอบชอบหลอก: เบอร์โทร และ รหัสนักศึกษา เป็น ข้อความ (String) เพราะไม่ได้นำไปคำนวณ!

END FOR

6. โครงสร้างการทำงาน 3 แบบ & เจาะลึก Loop

อัลกอริทึมทุกโปรแกรมบนโลกนี้ประกอบด้วย 3 โครงสร้างนี้เท่านั้น

⬇️

1. ลำดับ (Sequence)

ทำทีละบรรทัดจากบนลงล่าง ไม่มีข้าม ไม่มีย้อนกลับ เช่น รับค่า ➔ คำนวณ ➔ แสดงผล

🔀

2. เงื่อนไข (Selection)

มีทางเลือกให้ตัดสินใจ (จริง/เท็จ) เช่น IF..THEN, IF..ELSE, ขั้นบันได

🔁

3. วนซ้ำ (Iteration / Loop)

ทำงานซ้ำชุดเดิมตามจำนวนครั้งหรือจนกว่าเงื่อนไขจะสั่งหยุด เช่น FOR, WHILE, DO..WHILE

🔍 ตารางเปรียบเทียบการวนซ้ำ (ข้อสอบออกชัวร์ 100%):

FOR

เมื่อไหร่ใช้: รู้จำนวนรอบแน่นอน

มีตัวนับรอบจัดการให้ เช่น FOR i = 1 TO 5

รอบต่ำสุด: 0 หรือตามช่วง
WHILE

เมื่อไหร่ใช้: ไม่รู้จำนวนรอบแน่ชัด

เช็คเงื่อนไขก่อนทำ ถ้าเท็จแต่แรกจะไม่ทำเลย

รอบต่ำสุด: 0 ครั้ง
DO..WHILE

เมื่อไหร่ใช้: วนรับค่าจนกว่าจะถูก

ทำก่อน 1 รอบเสมอ แล้วค่อยตรวจเงื่อนไขท้ายรอบ

รอบต่ำสุด: 1 ครั้งเสมอ!

คำนวณปริมาตรทรงกระบอก (ค่าคงที่ PI)

🥫

โจทย์: รับค่าความสูง (H) และรัศมี (R) ของทรงกระบอก คำนวณหาปริมาตรโดยกำหนดให้ค่า $\pi$ เป็น ค่าคงที่เท่ากับ 3.14 (สูตร: $Volume = \pi imes R imes R imes H$)

✍️ เขียนใส่กระดาษ: อย่าลืมกำหนดค่าคงที่ SET PI = 3.14 ก่อนเริ่มคำนวณนะ!
ค่าคงที่: PI = 3.14 (กำหนดไว้ตายตัว)
Input: R (รัศมี), H (ความสูง)
Process: volume = PI * R * R * H
Output: volume (ปริมาตร)
BEGIN
  SET PI = 3.14
  INPUT R
  INPUT H
  SET volume = PI * R * R * H
  OUTPUT volume
END

คำนวณค่าดัชนีมวลกาย (BMI)

⚖️

โจทย์: รับค่า น้ำหนัก (weight เป็นกิโลกรัม) และ ส่วนสูง (height เป็นเมตร) คำนวณหาค่า BMI ตามสูตร: $BMI = weight / (height imes height)$ แล้วแสดงผล

✍️ เขียนใส่กระดาษ: ระวังเรื่องวงเล็บตอนเขียนสูตรหารด้วยส่วนสูงกำลังสองนะ!
Input: weight, height
Process: bmi = weight / (height * height)
Output: bmi
BEGIN
  INPUT weight
  INPUT height
  SET bmi = weight / (height * height)
  OUTPUT bmi
END

ส่วนลด 1 เงื่อนไข (IF..THEN ทางเลือกเดียว)

🏷️

โจทย์: ร้านค้าลดราคา 10% เมื่อยอดซื้อ ตั้งแต่ 1,000 บาทขึ้นไป หากไม่ถึงเกณฑ์ให้ชำระตามยอดเดิม จงเขียนรหัสเทียมคำนวณยอดเงินที่ต้องชำระ (payment)

✍️ ทริคเด็ดในกระดาษ: กำหนด SET payment = total ไว้ก่อน ถ้าเข้าเกณฑ์ค่อยลด!
Input: total (ยอดซื้อ)
เตรียมยอด: payment = total
เงื่อนไข: IF total >= 1000 THEN payment = total - (total * 0.10)
Output: payment (ยอดชำระ)
BEGIN
  INPUT total
  SET payment = total
  IF total >= 1000 THEN
    SET payment = total - (total * 0.10)
  END IF
  OUTPUT payment
END

ส่วนลด 2 ทางเลือก (IF..THEN..ELSE)

🛍️

โจทย์: ถ้ายอดซื้อ ตั้งแต่ 1,000 บาทขึ้นไป ลด 10% แต่ถ้า น้อยกว่า 1,000 บาท ลด 5% จงคำนวณส่วนลด (discount) และยอดชำระสุทธิ (payment)

✍️ เขียนใส่กระดาษ: ใช้ IF สำหรับเงื่อนไขแรก และ ELSE สำหรับกรณีที่เหลือ!
Input: total
Condition: IF total >= 1000 THEN discount = total * 0.10 ELSE discount = total * 0.05
Process รวม: payment = total - discount
Output: discount, payment
BEGIN
  INPUT total
  IF total >= 1000 THEN
    SET discount = total * 0.10
  ELSE
    SET discount = total * 0.05
  END IF
  SET payment = total - discount
  OUTPUT discount
  OUTPUT payment
END

โจทย์: คำนวณส่วนลดตามขั้นบันได:
• ตั้งแต่ 3,000 บาทขึ้นไป ลด 20%
• ตั้งแต่ 2,000 แต่ไม่ถึง 3,000 ลด 15%
• ตั้งแต่ 1,000 แต่ไม่ถึง 2,000 ลด 10%
• ต่ำกว่า 1,000 บาท ลด 5%

✍️ เทคนิคบนกระดาษ: เช็คจาก "ค่ามากไปหาค่าน้อย" จะทำให้เงื่อนไขสั้นและไม่ต้องเขียนช่วงซ้ำซ้อน!
1. IF total >= 3000 (ลด 20%)
2. ELSE IF total >= 2000 (ลด 15%)
3. ELSE IF total >= 1000 (ลด 10%)
4. ELSE (ลด 5%)

    SET discount = total * 0.20

    SET discount = total * 0.15
  ELSE IF total >= 1000 THEN
    SET discount = total * 0.10
  ELSE
    SET discount = total * 0.05
  END IF
  SET payment = total - discount

  OUTPUT payment
END

รับราคาสินค้า 5 ชิ้น & สะสมยอดรวม (FOR Loop)

🛒

โจทย์: ต้องการรับราคาสินค้า จำนวน 5 รายการ จากผู้ใช้ แล้วคำนวณแสดงยอดรวมทั้งหมด (total) ออกทางหน้าจอ

✍️ ข้อควรระวังสุดๆ บนกระดาษ: ต้องมี SET total = 0 อยู่นอกลูปก่อนเริ่มวนซ้ำเสมอ! ห้ามใส่ไว้ในลูปเด็ดขาด!
ตัวสะสมค่า (Accumulator): SET total = 0 (นอกลูป)
ลูป: FOR i = 1 TO 5
ในลูป: INPUT price แล้ว total = total + price
จบการวน: OUTPUT total (หลังจบลูป)
BEGIN
  SET total = 0
  FOR i = 1 TO 5
    INPUT price
    SET total = total + price
  END FOR
  OUTPUT total
END

รับราคาจนกว่าจะป้อน 0 เพื่อจบ (WHILE Loop)

🛑

โจทย์: รับราคาสินค้าไปเรื่อยๆ แล้วสะสมยอดรวม โดยผู้ใช้จะ ป้อนเลข 0 เมื่อต้องการจบรายการ (ไม่ทราบจำนวนชิ้นแน่นอนล่วงหน้า)

✍️ จุดสังเกตในกระดาษ: ต้องรับค่า INPUT price ครั้งแรกก่อนเข้า WHILE เพื่อให้มีค่ามาตรวจเงื่อนไขรอบแรก!
1. SET total = 0
2. INPUT price (รับค่าแรก)
3. WHILE price > 0 DO (ตราบใดที่ยังไม่ใส่ 0)
    total = total + price
    INPUT price (รับตัวต่อไป)
4. END WHILE ➔ OUTPUT total
BEGIN
  SET total = 0
  INPUT price
  WHILE price > 0 DO
    SET total = total + price
    INPUT price
  END WHILE
  OUTPUT total
END

รับค่าซ้ำจนกว่าจะถูกต้อง (DO..WHILE Loop)

🔁

โจทย์: ให้ผู้ใช้ป้อนจำนวนสินค้า (quantity) ซึ่งต้องมีค่า มากกว่า 0 เท่านั้น หากป้อนค่าติดลบหรือ 0 ให้วนรับค่าใหม่ซ้ำจนกว่าจะถูกต้อง จึงจะแสดงผลลัพธ์

✍️ จุดเด่นบนกระดาษ: ใช้ DO ขึ้นต้นเพื่อรับค่าก่อน 1 รอบ แล้วใส่ WHILE quantity <= 0 ท้ายรอบ!
เงื่อนไขให้ทำซ้ำต่อ: quantity <= 0 (ตราบใดที่ยังผิด ให้รับใหม่)
เมื่อหลุดลูป: แสดงค่า quantity ที่ถูกต้อง
BEGIN
  DO
    INPUT quantity
  WHILE quantity <= 0
  OUTPUT quantity
END
